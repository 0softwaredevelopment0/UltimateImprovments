## ✅ Added (новое)

### `lava_walker` — Lava Walker ❄️🔥
Frost Walker для **лавы**. Уровни **1–255**, только ботинки.

- Лава под ногами временно превращается в **обсидиан**
- Радиус = уровень чара: ур. 1 → 1×1, ур. 2 → 3×3 … кап **16 → 31×31** (961 блок за шаг)
- Созданные блоки **таят** обратно в лаву через случайные **20–45 с** (как frosted ice); блок, на котором стоишь, не растает первым
- Конвертируются **оба слоя**: под ногами (корка для ходьбы) и на уровне ног (можно «выплывать» вброд)
- Стол зачарований — **только третий слот** (тот же гейт min-cost, что у остальных чар); есть в торговле жителей и экипировке мобов; **нет** в random loot (анти-абуза книг)
- **Sneak** отключает конверсию (аккуратные работы у лавопадов)
- **Без защиты от поджига** — первый шаг в свежую лаву может поджечь
- Тающие плиты **переживают рестарт**: реестр в общем SQLite (`lava_walker_melts`: координаты + точный BlockData лавы + wall-clock дедлайн; автосейв 5 мин + сейв при выключении)
- При таянии лава возвращается **точно исходной** (источник остаётся источником, поток — своим уровнем) + принудительный block update — лава сразу течёт
- **Цена:** каждый созданный блок = **−1 прочность ботинкам** (макс. радиус = до 961 прочности за шаг)

### `armor_trim_effects` — эффекты тримов 💎
Зельевые эффекты за **материал трима** брони (слиток/кристалл из кузнечного стола = цвет окантовки). **Узор (sentry/dune/…) не важен.**

- Юниты в конфиге (`armor_trim_effects`): список материалов + правило + эффект
- Материалы (реестр Paper — датапак-материалы тоже работают): amethyst, copper, diamond, emerald, gold, iron, lapis, netherite, quartz, redstone, resin
- Правила: `MIN` (активация от `count` деталей, уровень фиксированный) / `EXACT` (уровень = число деталей)
- **Дефолт: все 11 материалов, MIN + count 1** (лвл I без роста — анти-абуз), эффекты:
  | Материал | Эффект |
  |---|---|
  | netherite | Fire Resistance |
  | iron | Resistance |
  | diamond | Absorption |
  | gold | Haste |
  | emerald | Hero of the Village |
  | amethyst | Regeneration |
  | copper | Water Breathing |
  | lapis | Night Vision |
  | quartz | Speed |
  | redstone | Strength |
  | resin | Slow Falling |
- `particles/ambient/icon` по умолчанию **false** (полностью «тихие»)
- Юниты работают параллельно; снял деталь — эффект истекает сам

### Чары брони на элитре 🪽
**Flight, Levitation, Igniting, Curse of Vulnerability** теперь ставятся на элитру:
- стол / наковальня / `/ui enchant` принимают элитру (датапак-теги)
- PDC-failsafe синхает слот груди (элитра там живёт)
- Igniting/Vulnerability видят элитру в эффектах (она не входит в `getArmorContents()`)

## ⚖️ Changed (баланс и правки поведения)

- **Flight ✕ Repairing (слот груди)** — Repairing на надетом нагруднике/элитре **отключает полёт**, пока деталь не снять. Почему только грудь: она платит за собственный дрейн двигателя — починить её = сделать полёт вечным. Repairing на других деталях работает, нагрудник видимо ветшает
- **Attack AoE** — затухание урона убрано (каждая цель получает полный удар), радиус = уровень с **капом 10**
- **Container Stealing** — уровни **1–10**; уровень N = **N×10%** шанс сработать (10 = всегда). Провал ролла = полностью ванильный брейк: пустой контейнер падает, ресы высыпаются — **ничего не уничтожается**. **Шалкеры исключены** (ваниль итак сохраняет их содержимое)
- **Lava Walker** — платит ботинками (см. выше)
- **Flight** — активно летаешь: **весь сет** теряет по 1 прочности/сек (раньше только нагрудник)
- **Flight** — **глайд** на зачарованной элитре тоже платит: 1 прочность нагрудника/сек (глайд = тот же двигатель)
- **Levitation** — активно бустишься (держишь прыжок): −1 прочность **нагрудника**/сек; отпустил — бесплатно. Дешевле Flight, как и положено «менее ценной» чаре

## 🔧 Fixed (исправлено)

- **Lava Walker душил игрока** — конверсия захватывала слои ног и головы: в свой хитбокс ставился твёрдый обсидиан (ванильное удушение + застревание). Теперь свои ноги/голова скипаются
- **Lava Walker: «щит от таяния» работал по кэшу** — ушёл игрок, а блок не таял вечно; пришёл сбоку — плита таяла под ногами. Теперь живая проверка bounding box'ов
- **Lava Walker срабатывал дважды** — листенер регистрировался два раза в модуле (ручная + через register())
- **Container Stealing обходил protection-плагины** — содержимое стиралось ДО того, как WorldGuard отменял брейк → оставался выграбленный сундук. Теперь MONITOR + следующий тик: отменённый брейк = сундук нетронут
- **Container Stealing уничтожал содержимое** (фикс из beta.2, сохраняется) — контейнер падает с содержимым в ванильном NBT (BlockStateMeta), тултип показывает лут, установка восстанавливает

## 📦 Установка

1. Взять архив `UltimateImprovments-1.8.3-beta.3-jars.tar`
2. Распаковать все `UI-*-1.8.3-beta.3-all.jar` в `plugins/`
3. Удалить старые версии UI-*.jar
4. Запустить сервер (UI-Datapack сам зарегистрирует чары)

**Требования:** Paper (или форк) 26.2, Java 25+

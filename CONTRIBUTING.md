# Contributing to Ultimate Improvments

Thanks for your interest in the project! Here's how you can get involved.

---

## 💬 Questions & Support

**If you have a question about configuration, commands, or how a feature works — please ask it in [Discussions](https://github.com/rizer001-Development/UltimateImprovments/discussions).**

Discussions are the preferred channel for:

- How do I configure X?
- What does this command do?
- Why is feature Y not working on my server?
- General usage help

> 💡 **Tip:** Use the **Q&A** category when posting a question. This helps others find your question and the accepted answer in the future.

---

## 🐛 Bug Reports

Found a bug? Please [open an Issue](https://github.com/rizer001-Development/UltimateImprovments/issues/new) with:

- **Server version** (e.g. `Paper 26.2`)
- **Plugin version** (e.g. `1.8.2`)
- **Steps to reproduce** the problem
- **Console error** (if any)

---

## ✨ Feature Requests

Have an idea? Open an [Issue](https://github.com/rizer001-Development/UltimateImprovments/issues/new) with the label `enhancement` and describe:

- What you'd like to see
- Why it would be useful
- Any examples or mockups

---

## 🔧 Pull Requests

Pull requests are welcome! For non-trivial changes, please open an Issue first to discuss the approach.

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Test on a Paper 26.2+ server
5. Open a Pull Request with a clear description

---

## 📖 Documentation

Improvements to `GUIDE.md` or `README.md` are always appreciated. If you notice something outdated or missing, feel free to submit a PR.

---

## 📁 Project Structure

```
UltimateImprovments/
├── ui-core/          Core module: commands, config, database, modules
├── ui-shared/        Shared utilities across modules
├── ui-chat/          Custom chat, pings, formats
├── ui-clans/         Clan system
├── ui-combat/        Custom items, enchantments, combat
├── ui-energy/        Energy network, reactor, machines
├── ui-essentials/    Homes, spawn, teleport, utilities
├── ui-other/         Turrets, radiation, misc features
├── ui-punish/        Ban, mute, kick, warn system
└── ui-anticheat/     Anti-cheat, packet guard
```
